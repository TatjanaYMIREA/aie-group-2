# HW10-11 – компьютерное зрение в PyTorch: CNN, transfer learning, detection/segmentation

## 1. Кратко: что сделано

- **Часть A**: выбран датасет **STL10** (рекомендованный преподавателем вариант). Датасет содержит 10 классов, изображения 96×96, что позволяет наглядно продемонстрировать эффект аугментаций и transfer learning.
- **Часть B**: выбран трек **segmentation** на датасете **OxfordIIITPet**. Это естественный выбор для демонстрации сегментации: изображения домашних питомцев с четкими масками, понятный foreground (питомец vs фон).
- **Что сравнивалось**: в части A сравнивались 4 режима (простая CNN без/с аугментациями, ResNet18 с замороженным backbone и с fine-tuning). В части B сравнивались 2 режима постобработки масок (разные пороги и удаление маленьких компонент).

## 2. Среда и воспроизводимость

- **Python**: 3.10+
- **torch / torchvision**: 2.10.0+cu128 / 0.25.0+cu128
- **Устройство**: GPU (CUDA)
- **Seed**: 42
- **Как запустить**: открыть `HW10-11.ipynb` и выполнить Run All. Для полного обучения (не fast mode) установить `FAST_MODE = False` в блоке конфигурации.

## 3. Данные

### 3.1. Часть A: классификация

- **Датасет**: STL10
- **Разделение**: train/val/test (80/20 от train, фиксированный seed)
- **Базовые transforms**: ToTensor() + Normalize(STL10_MEAN, STL10_STD)
- **Augmentation transforms**: RandomHorizontalFlip(p=0.5) + RandomRotation(10) + ColorJitter(brightness=0.2, contrast=0.2)
- **Комментарий**: STL10 содержит 10 классов (самолеты, автомобили, птицы и т.д.) с изображениями 96×96. Это более сложный датасет, чем CIFAR-10, что позволяет лучше увидеть преимущества transfer learning. Классы сбалансированы, задача умеренной сложности.

### 3.2. Часть B: structured vision

- **Датасет**: OxfordIIITPet
- **Трек**: segmentation
- **Что считается ground truth**: маски сегментации с тремя значениями (1 — фон, 2 — питомец, 3 — контур). Для бинарной оценки foreground считались пиксели со значением ≥ 2.
- **Какие предсказания использовались**: выходы модели DeepLabV3 с 3 классами (softmax), постобработанные в бинарные маски.
- **Комментарий**: OxfordIIITPet идеально подходит для демонстрации сегментации — изображения четкие, маски точные, задача интуитивно понятна. Модель DeepLabV3 уже имеет веса, обученные на COCO, что позволяет увидеть качество zero-shot переноса.

## 4. Часть A: модели и обучение (C1-C4)

- **C1 (simple-cnn-base)**: простая CNN из 3 блоков (conv+relu+conv+relu+pool) с классификатором. Без аугментаций. Параметров: ~1.2M.
- **C2 (simple-cnn-aug)**: та же архитектура, но с аугментациями (Flip+Rotation+ColorJitter).
- **C3 (resnet18-head-only)**: предобученный ResNet18, backbone заморожен, обучается только голова (последний линейный слой). Параметров: ~5k.
- **C4 (resnet18-finetune)**: тот же ResNet18, но разморожен layer4 и голова, с разными learning rates (1e-4 для backbone, 1e-3 для головы).

Дополнительно:
- **Loss**: CrossEntropyLoss
- **Optimizer(ы)**: Adam (для C1,C2,C3), Adam с группировкой параметров (для C4)
- **Batch size**: 128
- **Epochs (макс)**: 12 (для полного режима)
- **Критерий выбора лучшей модели**: максимальная accuracy на валидации

## 5. Часть B: постановка задачи и режимы оценки (V1-V2)

- **Модель**: DeepLabV3 с 3 выходными классами (предобученная, без дообучения)
- **Что считается foreground**: класс 1 (питомец) из выхода модели
- **V1**: базовая постобработка — порог 0.35 (подобран эмпирически по распределению вероятностей)
- **V2**: альтернативная постобработка — порог 0.4 + удаление компонент связности меньше 50 пикселей
- **Как считался mean IoU**: бинарное пересечение по пикселям между предсказанной маской и ground truth (питомец)
- **Дополнительные метрики**: pixel precision и pixel recall

**Короткая сводка:**

- **Лучший эксперимент части A**: C4 (ResNet18 с fine-tuning)
- **Лучшая val_accuracy**: 0.947
- **Итоговая test_accuracy лучшего классификатора**: 0.963
- **Что дали аугментации (C2 vs C1)**: accuracy на тесте выросла с 0.443 до 0.479, хотя на валидации результаты были близки. Аугментации улучшили обобщающую способность.
- **Что дал transfer learning (C3/C4 vs C1/C2)**: колоссальный скачок — с ~0.45 до ~0.94. Предобученная на ImageNet модель несравнимо лучше справляется с распознаванием объектов.
- **Что оказалось лучше: head-only или partial fine-tuning**: fine-tuning (C4) дал +1.6% к валидационной accuracy и +2.7% к тестовой по сравнению с head-only (C3).
- **Что показал режим V1 во второй части**: при пороге 0.35 модель показывает precision 0.81 и recall 0.44, IoU=0.37. Модель уверена, когда предсказывает, но находит только половину пикселей питомца.
- **Что показал режим V2 во второй части**: повышение порога до 0.4 и удаление мелких компонент резко снизило все метрики (IoU=0.06). Модель без дообучения не генерирует достаточно высоких вероятностей для такого порога.
- **Как интерпретируются метрики второй части**: необученная модель может находить питомцев, но неуверенно. Для практического применения необходимо дообучение.

## 7. Анализ

Простая CNN на STL10 показывает ожидаемо низкие результаты (~45% accuracy) — датасет сложнее CIFAR-10, и архитектура без предобучения не может выучить хорошие признаки за несколько эпох. Аугментации дают небольшой, но устойчивый прирост на тесте (+3.6%), что подтверждает их пользу для обобщения.

Transfer learning с ResNet18 кардинально меняет ситуацию: accuracy подскакивает до 93-96%. Это демонстрирует силу предобученных на ImageNet моделей — они уже умеют выделять универсальные визуальные признаки. Интересно, что даже head-only (обучение только классификатора) дает 93.6% — замороженный backbone работает как отличный feature extractor.

Fine-tuning layer4 добавляет еще ~2.7% к тестовой точности. Это показывает, что адаптация последних слоев под специфику датасета (STL10 отличается от ImageNet по домену) всё же полезна, хотя и не критична.

В части B выбрана метрика IoU — стандарт для сегментации. Она честно показывает долю пересечения предсказания с истиной. Режим V1 (порог 0.35) дал IoU=0.37, что для zero-shot переноса неплохо. V2 с более высоким порогом оказался слишком строгим — необученная модель просто не выдает такие высокие вероятности. Наиболее показательные ошибки — модель либо не видит питомца совсем, либо "шумит" по краям объекта.

## 8. Итоговый вывод

- **Базовый конфиг классификации**: ResNet18 с fine-tuning layer4. Это дает максимальное качество (96.3% на тесте) при умеренных вычислительных затратах.
- **Главное про transfer learning**: предобученные модели — это "волшебная палочка" компьютерного зрения. Даже с замороженным backbone они превосходят самодельные CNN на порядок. Fine-tuning последних слоев дает дополнительный бонус.
- **Главное про сегментацию**: корректная метрика (IoU) и визуализация критически важны. Без дообучения модель может показывать разумные результаты только при тщательном подборе порога. Для реальных задач нужно обязательно дообучать на целевых данных.
