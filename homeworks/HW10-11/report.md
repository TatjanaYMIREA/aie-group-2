# HW10-11 – компьютерное зрение в PyTorch: CNN, transfer learning, segmentation

## 1. Кратко: что сделано

- **Часть A**: выбран датасет **STL10** (рекомендованный преподавателем вариант). Датасет содержит 10 классов, изображения 96×96, что позволяет наглядно продемонстрировать эффект аугментаций и transfer learning.
- **Часть B**: выбран трек **segmentation** на датасете **OxfordIIITPet**. Это естественный выбор для демонстрации сегментации: изображения домашних питомцев с четкими масками, понятный foreground (питомец vs фон).
- **Что сравнивалось**: в части A сравнивались 4 режима:
  - C1: простая CNN без аугментаций
  - C2: простая CNN с аугментациями
  - C3: ResNet18 с замороженным backbone (head-only)
  - C4: ResNet18 с fine-tuning (layer4 + fc)
- В части B сравнивались 2 режима постобработки масок:
  - V1: порог 0.5 (базовая постобработка)
  - V2: порог 0.7 + удаление маленьких компонент связности (min_size=100)

## 2. Среда и воспроизводимость

- **Python**: 3.10+
- **torch / torchvision**: 2.10.0+cu128 / 0.25.0+cu128
- **Устройство**: CPU (CUDA не обнаружено)
- **Seed**: 42 (фиксирован для всех random-операций)
- **Как запустить**: открыть `HW10-11.ipynb` и выполнить Run All. Для полного обучения (не fast mode) установить `FAST_MODE = False` в блоке конфигурации.

## 3. Данные

### 3.1. Часть A: классификация

- **Датасет**: STL10
- **Разделение**: train/val/test (80/20 от train, фиксированный seed)
- **Базовые transforms**: ToTensor() + Normalize(STL10_MEAN, STL10_STD)
- **Augmentation transforms**: RandomHorizontalFlip(p=0.5) + RandomRotation(10) + ColorJitter(brightness=0.2, contrast=0.2)
- **Комментарий**: STL10 содержит 10 классов (самолеты, автомобили, птицы и т.д.) с изображениями 96×96. Это более сложный датасет, чем CIFAR-10, что позволяет лучше увидеть преимущества transfer learning. Классы сбалансированы, задача умеренной сложности.

### 3.2. Часть B: structured vision

- **Датасет**: OxfordIIITPet
- **Трек**: segmentation
- **Что считается ground truth**: маски сегментации с тремя значениями (1 — фон, 2 — питомец, 3 — контур). Для бинарной оценки foreground считались пиксели со значением ≥ 2.
- **Какие предсказания использовались**: выходы модели DeepLabV3 (предобученной на COCO), постобработанные в бинарные маски.
- **Комментарий**: OxfordIIITPet идеально подходит для демонстрации сегментации — изображения четкие, маски точные, задача интуитивно понятна. Модель DeepLabV3 уже имеет веса, обученные на COCO, что позволяет оценить качество zero-shot переноса.

## 4. Часть A: модели и обучение (C1-C4)

- **C1 (simple-cnn-base)**: простая CNN из 3 блоков (conv+relu+conv+relu+maxpool) с классификатором. Без аугментаций. Параметров: ~1.2M.
- **C2 (simple-cnn-aug)**: та же архитектура, но с аугментациями (RandomHorizontalFlip + RandomRotation + ColorJitter).
- **C3 (resnet18-head-only)**: предобученный ResNet18, backbone заморожен, обучается только голова (последний линейный слой). Параметров: ~5k.
- **C4 (resnet18-finetune)**: тот же ResNet18, но разморожен layer4 и голова, с разными learning rates (1e-4 для backbone, 1e-3 для головы).

**Дополнительно:**
- **Loss**: CrossEntropyLoss
- **Optimizer(ы)**: Adam (для C1,C2,C3), Adam с группировкой параметров (для C4)
- **Batch size**: 128
- **Epochs (fast mode)**: 4 для C1/C2, 3 для C3/C4
- **Критерий выбора лучшей модели**: максимальная accuracy на валидации

## 5. Часть B: постановка задачи и режимы оценки (V1-V2)

- **Модель**: DeepLabV3 с 21 выходным классом (предобученная на COCO, без дообучения)
- **Что считается foreground**: класс, соответствующий питомцу (в COCO: 3 — cat, 4 — dog). Для упрощения использовался класс 3 (cat).
- **V1**: базовая постобработка — порог 0.5
- **V2**: альтернативная постобработка — порог 0.7 + удаление компонент связности меньше 100 пикселей
- **Как считался mean IoU**: бинарное пересечение по пикселям между предсказанной маской и ground truth (питомец ≥ 2)
- **Дополнительные метрики**: pixel precision и pixel recall

## 7. Анализ

**Классификация:**
Простая CNN на STL10 показывает ожидаемо низкие результаты (~45% val accuracy) — датасет сложнее CIFAR-10, и архитектура без предобучения не может выучить хорошие признаки за несколько эпох. Аугментации в режиме fast mode не дали значимого прироста на валидации, но их польза для обобщения проявляется при полном обучении.

Transfer learning с ResNet18 кардинально меняет ситуацию: accuracy подскакивает до 93-96%. Это демонстрирует силу предобученных на ImageNet моделей — они уже умеют выделять универсальные визуальные признаки. Интересно, что даже head-only (обучение только классификатора) дает 93.1% — замороженный backbone работает как отличный feature extractor.

Fine-tuning layer4 добавляет еще ~1.6% к валидационной точности и ~2.7% к тестовой. Это показывает, что адаптация последних слоев под специфику датасета (STL10 отличается от ImageNet по домену) всё же полезна.

**Сегментация:**
В части B выбрана метрика IoU — стандарт для сегментации. Она честно показывает долю пересечения предсказания с истиной. Режим V1 (порог 0.5) дал IoU=0.30, что для zero-shot переноса приемлемо. V2 с более высоким порогом (0.7) оказался слишком строгим — необученная модель просто не выдает такие высокие вероятности, IoU упал до 0.09. Наиболее показательные ошибки — модель либо не видит питомца совсем, либо "шумит" по краям объекта.

## 8. Итоговый вывод

- **Базовый конфиг классификации**: ResNet18 с fine-tuning layer4. Это дает максимальное качество (96.3% на тесте) при умеренных вычислительных затратах.
- **Главное про transfer learning**: предобученные модели — это "волшебная палочка" компьютерного зрения. Даже с замороженным backbone они превосходят самодельные CNN на порядок. Fine-tuning последних слоев дает дополнительный бонус.
- **Главное про сегментацию**: корректная метрика (IoU) и визуализация критически важны. Без дообучения модель может показывать разумные результаты только при тщательном подборе порога. Для реальных задач нужно обязательно дообучать на целевых данных.
