# Итоговый проект по курсу «Инженерия Искусственного Интеллекта»

В этой папке находится итоговый мини-проект по курсу.  
Проект демонстрирует применение методов и инструментов инженерии ИИ: работу с данными, модели, пайплайны, сервис, эксперименты и воспроизводимость.

---

## 1. Паспорт проекта

- **Название проекта:** Прогнозирование индекса счастья на основе экономических и социальных показателей
- **Автор:** `<Ваше ФИО>`
- **Группа:** `<Ваша группа>`
- **Контакт:** `<@telegram или email>`

- **Краткое описание:**  
  Проект посвящён построению сервиса предсказания индекса счастья (Life Ladder) по данным Всемирного доклада счастья.  
  Используются открытые данные World Happiness Report (2005–2023), 8 экономических и социальных признаков.  
  Результат – REST API на FastAPI, который по 8 показателям возвращает предсказанный индекс счастья (от 0 до 10).

---

## 2. Структура проекта

Проект организован в следующей структуре:

- `requirements.txt` – зависимости проекта (библиотеки Python).
- `pyproject.toml` – конфигурация проекта и зависимости (для `uv`).
- `report.md` – отчёт по проекту (постановка задачи, данные, эксперименты, результаты).
- `self-checklist.md` – чеклист самопроверки проекта перед сдачей.
- `notebooks/` – экспериментальные ноутбуки:
  - `exp01_eda_baseline.ipynb` – разведочный анализ данных (EDA) и baseline модель.
  - `exp02_model_tuning.ipynb` – сравнение моделей (LR, Ridge, Lasso, Random Forest, Gradient Boosting) и тюнинг гиперпараметров.
- `src/happiness/` – основной код сервиса:
  - `api.py` – FastAPI приложение (эндпоинты `/health`, `/predict`, `/docs`).
  - `predict.py` – загрузка модели и функция предсказания.
  - `schemas.py` – Pydantic модели для валидации входных/выходных данных.
  - `cli.py` – CLI интерфейс для предсказаний из командной строки.
- `artifacts/` – сохранённая модель и метаданные:
  - `happiness_model.pkl` – сериализованная модель Gradient Boosting.
  - `features.json` – список признаков.
  - `model_metadata.json` – метрики, параметры, важность признаков.
- `configs/` – конфигурационные файлы:
  - `.env.example` – шаблон переменных окружения.
- `data/` – демонстрационные данные:
  - `sample_data.json` – примеры запросов для тестирования.
- `tests/` – тесты:
  - `test_api.py` – тесты эндпоинтов `/health` и `/predict`.

## 3. Требования и установка

### 3.1. Требования

- Python `>= 3.11`
- [uv](https://docs.astral.sh/uv/) – быстрый менеджер пакетов (рекомендуется)

### 3.2. Установка окружения

```bash
# Перейти в папку проекта
cd project

# Установить зависимости через uv (создаст виртуальное окружение .venv)
uv sync

# Активировать виртуальное окружение (опционально, uv run сделает это автоматически):
# Windows:
.venv\Scripts\activate
# Linux / macOS:
source .venv/bin/activate

## 4. Как запустить проект

### 4.1. Запуск сервиса (API)

```bash
cd project
uv run uvicorn happiness.api:app --reload --port 8000
```

Сервис будет доступен по адресу: `http://localhost:8000`

**Эндпоинты:**

| Эндпоинт | Метод | Описание |
|----------|-------|----------|
| `/health` | GET | Проверка работоспособности сервиса |
| `/predict` | POST | Предсказание индекса счастья |
| `/docs` | GET | Swagger UI документация |

**Пример запроса к `/predict`:**

```bash
curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d '{
    "Log_GDP_per_capita": 9.5,
    "Social_support": 0.8,
    "Healthy_life_expectancy_at_birth": 65.0,
    "Freedom_to_make_life_choices": 0.7,
    "Generosity": 0.1,
    "Perceptions_of_corruption": 0.7,
    "Positive_affect": 0.6,
    "Negative_affect": 0.3
  }'
```

**Пример ответа:**

```json
{
  "life_ladder": 5.202
}
```

### 4.2. Запуск CLI (командная строка)

```bash
uv run happiness predict --input data/sample_data.json
```

### 4.3. Запуск через Docker (опционально)

```bash
cd project
docker build -t happiness-api .
docker run -p 8000:8000 happiness-api
```

## 5. Данные

**Источник данных:** World Happiness Report dataset  
**Ссылка:** [World Happiness Report 2023 на Kaggle](https://www.kaggle.com/datasets/ajaypalsinghlo/world-happiness-report-2023)

**Период:** 2005–2023  
**Охват:** 165 стран  
**Объём:** 2371 запись

**Признаки (8 числовых):**

| Признак | Описание |
|---------|----------|
| Log GDP per capita | Логарифм ВВП на душу населения |
| Social support | Уровень социальной поддержки |
| Healthy life expectancy at birth | Ожидаемая продолжительность здоровой жизни |
| Freedom to make life choices | Свобода принятия жизненных решений |
| Generosity | Уровень щедрости |
| Perceptions of corruption | Восприятие коррупции |
| Positive affect | Позитивный аффект |
| Negative affect | Негативный аффект |

**Целевая переменная:** `Life Ladder` (индекс счастья, 0–10)

**Где лежат данные:**  
- Полный датасет скачивается автоматически в ноутбуках из Colab.  
- Демонстрационные примеры хранятся в `data/sample_data.json`.

## 8. Ограничения и дальнейшая работа

### Текущие ограничения

- Модель обучена на данных до 2023 года, не учитывает временную динамику.
- Пропуски в данных (2-5%) были удалены, возможна потеря информации.
- Не проводился тюнинг для Random Forest.
- Нейросетевые модели не рассматривались.

### Дальнейшая работа

- **Модель:** тюнинг Random Forest, ансамбль моделей (stacking), добавление временных признаков.
- **Сервис:** кэширование предсказаний (Redis), batch-обработка, аутентификация.
- **Данные:** использование более свежих данных (2024, 2025), добавление новых признаков (образование, экология).
